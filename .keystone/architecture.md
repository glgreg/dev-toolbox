# Architecture

## 1. System Overview

`dev.gregorium.com` is organized as an independent-utility toolbox served from a static frontend root (`dist/`) deployed on Vercel, backed by two stateless serverless proxy runtimes for operations that cannot execute directly in the browser due to CORS or third-party anti-bot policies:

1. **Tier 1 (100% Client-Side Execution)**: Utilities run entirely in the browser using native Web APIs (`DOMParser`, `FileReader`, `Blob`, `localStorage`, `navigator.clipboard`).
2. **Tier 2 (Hybrid Serverless Proxies)**:
   - **Vercel Serverless Proxy (`dist/api/chatgpt.js`)**: Same-origin Node.js/Edge dual-compatible handler that fetches public ChatGPT shared conversations via SSR React Router Turbo Stream extraction with backend API fallback.
   - **Cloudflare Worker Proxy (`worker/src/index.js`)**: Stateless Worker with Cloudflare KV (`DEV_INDEXNOW_KV`) per-IP rate limiting for IndexNow key verification, remote XML sitemap fetching, multi-engine IndexNow submission, and ChatGPT share fallback.

## 2. Technology Stack

- **Language / Runtime**: Vanilla JavaScript (ES Modules in browser/Worker, dual CJS/ESM in Vercel Node.js serverless), HTML5, Vanilla CSS.
- **Frameworks**: None (zero UI or CSS frameworks by design).
- **Data**: Browser `localStorage` for user preferences/config; Cloudflare KV (`DEV_INDEXNOW_KV`) for ephemeral IP rate-limit counters.
- **Infrastructure**: Vercel (hosts `dist/` as project root and `dist/api/` serverless functions) and Cloudflare Workers (`worker/` deployed via Wrangler).
- **Tooling & Testing**: Bun (`bun test/e2e.test.js`), Puppeteer (`puppeteer-core`) with headless Chromium, Vercel CLI, and Wrangler.

## 3. Structure and Patterns

- **Directory layout**:
  - `dist/`: Public root deployed to Vercel (`dist/index.html`, `dist/index.css`, `dist/index.js`, tool subdirectories, and `dist/api/`).
  - `dist/indexnow/`: IndexNow Submitter frontend tool.
  - `dist/chatgpt-exporter/`: ChatGPT Share Exporter frontend tool.
  - `dist/api/`: Vercel serverless functions co-deployed with the frontend.
  - `worker/`: Standalone Cloudflare Worker package (`worker/src/index.js`, `worker/wrangler.jsonc`).
  - `test/`: End-to-end browser and API test suite (`test/e2e.test.js`).
  - `docs/`: Supplemental human/agent reference docs ([`docs/README.md`](../docs/README.md)).
- **Design patterns**:
  - **Synchronous Theme Initialization**: Every HTML entry point evaluates `localStorage.getItem('theme')` and `prefers-color-scheme` inline inside `<head>` before painting to guarantee zero FOUC.
  - **Independent Tool Modules**: Each tool lives in `dist/<tool-name>/` with its own `index.html` and script, sharing only `../index.css` and `../index.js`.
  - **Environment-Aware Endpoint Resolution**: Frontend scripts detect `localhost` / `127.0.0.1` to route Worker requests to `http://localhost:8787` during local development and to the production `workers.dev` endpoint otherwise.

## 4. Integration Points

- **IndexNow Search Engine Endpoints**: `https://api.indexnow.org/indexnow`, `https://www.bing.com/indexnow`, and `https://yandex.com/indexnow` (sequentially queried by `worker/src/index.js`).
- **ChatGPT Public Shares**: `https://chatgpt.com/share/<shareId>` (SSR HTML stream) and `https://chatgpt.com/backend-api/share/<shareId>` (queried by `dist/api/chatgpt.js` and `worker/src/index.js`).
- **User-Specified Domains & Sitemaps**: Queried by `worker/src/index.js` during IndexNow key verification (`action=verify`) and sitemap extraction (`action=sitemap`).

## 5. Constraints

- **Zero Framework Bloat**: No React, Vue, Next.js, or Tailwind. Pure HTML5, CSS custom properties, and vanilla JS.
- **System Typography Only**: No external font `@import` or webfont network requests.
- **Root Folder Protection**: Vercel's root directory is `dist/`; `.keystone/`, `.stone.*.md`, `docs/`, and `worker/` live outside `dist/` so they are never exposed as public static files.
- **Near-Zero Cost & Abuse Prevention**: Public proxy endpoints must enforce strict input validation (UUID v4 regex for ChatGPT shares, 2MB cap for sitemaps) and IP rate limiting (500 requests/day + 2s cooldown in Cloudflare KV, failing open on KV errors).
