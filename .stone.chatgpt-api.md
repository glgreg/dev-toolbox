# ChatGPT Share Serverless Proxy

## Purpose and Design Decisions

Browsers cannot fetch `https://chatgpt.com/share/<shareId>` directly because of CORS restrictions, and cloud datacenter requests to ChatGPT's JSON endpoint are frequently blocked by bot protection. `dist/api/chatgpt.js` runs as a same-origin Vercel serverless function (`/api/chatgpt`) that extracts conversation payloads by first requesting the SSR HTML share page across multiple browser/crawler User-Agent profiles and decoding the embedded React Router Turbo Stream (`window.__reactRouterContext.streamController.enqueue(...)`), falling back to `https://chatgpt.com/backend-api/share/<shareId>`.

## Invariants

- Every request validates `shareId` against the UUID v4 hexadecimal pattern (`[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}`) before making any outbound fetch, preventing Server-Side Request Forgery (SSRF) and returning HTTP `400` on invalid input.
- `dist/api/chatgpt.js` supports both Vercel's Node.js `(req, res)` runtime (`handleNode`) and Web Standard `(request)` runtime (`handleEdge`), and exports `module.exports = handler; module.exports.default = handler;` (plus helper methods on `handler`) so Vercel's Node runner, Vitest unit tests (`test/unit/chatgpt-api.test.ts`), and the Playwright E2E server (`test/e2e/server.ts`) can invoke it directly.
- `parseTurboStream` caps recursion depth at `30` and memoizes unflattened indices in a `Map` to prevent stack overflows or exponential traversal on deeply nested or cyclic React Router payloads.
- Successful responses set `Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400` so repeated exports of the same share ID are served from the Vercel edge cache.

## Integration Contracts

- Endpoint: `GET` or `POST` `/api/chatgpt?shareId=<uuid>` (also accepts `url` query parameter or JSON body `{ shareId, url }`).
- Success response (`200 OK`): JSON conversation object containing `title`, `create_time`, and either `linear_conversation` or `mapping` + `current_node`.
- Error response (`400` / `404` / `500`): JSON `{ error: string, details?: Array<object> }`.

## Anti-Patterns

- Exporting a `config` object that forces the Edge runtime or breaking CommonJS/ESM dual exports in `dist/api/chatgpt.js`, which breaks either Vercel's Node serverless builder or the automated test suites.
- Forwarding unvalidated URLs or arbitrary path segments to `chatgpt.com`.
