# Toolbox Hub

## Purpose and Design Decisions

The central hub (`dist/index.html`, `dist/index.css`, `dist/index.js`) serves as the entry point for `dev.gregorium.com` and provides shared design tokens, typography, and theme toggling across every tool on the portal. It is built with vanilla HTML5, CSS custom properties, and native DOM event listeners so the initial page load and tool filtering execute in under a millisecond with zero framework runtime overhead.

## Invariants

- Theme selection (`data-theme="dark"` or `data-theme="light"`) is evaluated synchronously via an inline `<script>` inside `<head>` before `index.css` paints, preventing Flash of Unstyled Content (FOUC) on every page.
- Typography relies exclusively on system font stacks defined in `dist/index.css` so text renders immediately without external `@import` or webfont network requests.
- Vercel serves `dist/` as its project root (`dist/vercel.json` configures `cleanUrls: true`, cache-control headers, and `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy`), keeping repository metadata and backend worker sources outside the public web root.
- Keyboard navigation on the hub binds `/` to focus `#search-input` (when no input or textarea is focused) and `Escape` to clear and blur the filter.

## Integration Contracts

- Shared stylesheet `dist/index.css` and script `dist/index.js` are linked by all child tools (`../index.css`, `../index.js`) and expect `#theme-toggle` in the navigation bar to persist `localStorage.getItem('theme')`.
- Tool cards in `dist/index.html` reside inside `.card-grid` as `<article class="card">` elements filtered by `#search-input` against `card.textContent`, toggling `#search-empty` when zero cards match.

## Anti-Patterns

- Introducing UI frameworks (React, Vue, Tailwind) or external icon/font CDNs, which would break the zero-dependency, instant-paint guarantee.
- Moving theme detection out of the synchronous `<head>` script into `DOMContentLoaded`, which causes a visible light/dark flash on initial load.
