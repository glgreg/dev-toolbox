# ChatGPT Share Exporter

## Purpose and Design Decisions

The ChatGPT Share Exporter (`dist/chatgpt-exporter/index.html`, `dist/chatgpt-exporter/exporter.js`) converts public ChatGPT shared links (`https://chatgpt.com/share/<uuid>`) into downloadable `.md`, `.jsonl`, and `.txt` files or clipboard Markdown. It fetches the raw share payload from `chatgpt-api` (`/api/chatgpt`) and performs all turn extraction, formatting, preview rendering, and `Blob` file generation locally in the user's browser. Format specifications are documented in [`docs/chatgpt_exporter/README.md`](./README.md).

## Invariants

- Client-side validation (`extractShareId`) extracts and verifies a UUID v4 from `#input-share-url` before issuing any network request, displaying an inline error in `#fetch-status` if no valid UUID is present.
- `extractTurns(data)` supports both modern `data.linear_conversation` arrays and legacy `data.mapping` + `data.current_node` DAG parent traversal, filtering exclusively for non-empty `user` and `assistant` text turns.
- Exported `.jsonl` lines strictly contain `{ index, role, content }` (plus optional `model` and `timestamp`) serialized as one JSON object per line, matching standard fine-tuning and evaluation dataset schemas.
- DOM IDs `#input-share-url`, `#btn-fetch`, `#fetch-status`, `#export-card`, `#chat-title`, `#preview-panel`, `#tab-preview-md`, `#tab-preview-jsonl`, and `#tab-preview-txt` are relied upon by the automated browser test suite in `test/e2e.test.js`.

## Integration Contracts

- Depends on `hub` (`dist/index.css`, `dist/index.js`) for shared styling and theme management.
- Requests `GET /api/chatgpt?shareId=<uuid>` provided by `chatgpt-api` (`dist/api/chatgpt.js`).
- Verified end-to-end by `test/e2e.test.js` (`bun test`).

## Anti-Patterns

- Renaming or removing the core DOM selectors tested by `test/e2e.test.js` without updating the E2E suite.
- Assuming shared conversations only use `linear_conversation` and omitting the `mapping` DAG fallback.
