# IndexNow Submitter

## Purpose and Design Decisions

The IndexNow Submitter (`dist/indexnow/index.html`, `dist/indexnow/indexnow.js`) lets site owners generate IndexNow API keys, verify key file hosting, load URLs from manual input, remote XML sitemaps, or local `.xml`/`.csv`/`.txt` files, and submit them to search engines. Local file parsing (`FileReader`, `DOMParser`), URL deduplication, and configuration persistence (`localStorage`) run 100% in the browser, while cross-origin key verification, remote sitemap fetching, and IndexNow API submission route through `worker-proxy`. Detailed rate limits are documented in [`docs/index_now/API_LIMITS.md`](./API_LIMITS.md).

## Invariants

- `getApiUrl(action)` automatically routes to `http://localhost:8787/api/indexnow?action=${action}` when `window.location.hostname` is `localhost` or `127.0.0.1`, and to `https://dev-toolbox-indexnow.gustavo-l-gregorio.workers.dev` in production.
- Unless `#check-skip-verify` is explicitly checked, `submitToIndexNow()` executes `verifyKeyHosting()` first and aborts submission if the remote key file cannot be verified.
- URL lists are normalized, filtered to valid `http://` or `https://` prefixes, and deduplicated via `Set` before submission.
- Domain, API key, key location URL, and sitemap URL are persisted in `localStorage` (`indexnow_domain`, `indexnow_key`, `indexnow_key_location`, `indexnow_sitemap`), and auto-derived URLs only overwrite `keyLocation` or `sitemapUrl` when the user has not customized them (`hasCustomKeyLocation` / `hasCustomSitemap`).

## Integration Contracts

- Depends on `hub` (`dist/index.css`, `dist/index.js`) for layout, theme toggling, and styling tokens.
- Communicates with `worker-proxy` via `POST /api/indexnow?action=verify|sitemap|submit`.

## Anti-Patterns

- Calling `api.indexnow.org` or fetching remote sitemaps directly from browser `fetch()` without the Worker proxy, which fails due to browser CORS enforcement.
- Hardcoding the production Cloudflare Worker URL without the `localhost:8787` check, which breaks local Wrangler integration testing.
