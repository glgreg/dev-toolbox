# JWT Debugger & Inspector

## Purpose and Design Decisions

The JWT Debugger & Inspector (`dist/jwt/`) provides a privacy-first, zero-tracking tool for decoding, introspecting, and signing JSON Web Tokens. Unlike public online JWT debuggers that send customer credentials and secret keys over the internet, this module operates 100% locally in the developer's browser using native Web APIs (`crypto.subtle`, `TextEncoder`, `TextDecoder`, `btoa`, `atob`).

## Invariants

- All cryptographic operations (HMAC-SHA256, HMAC-SHA384, HMAC-SHA512) and token decoding execute entirely within browser memory; neither tokens nor secret keys are ever transmitted over the network.
- Base64URL encoding and decoding handles arbitrary UTF-8 characters and cross-realm byte buffers without padding corruption or external polyfills.
- Timestamp introspection evaluates expiration (`exp`), issue time (`iat`), and activation (`nbf`) relative to client system time, displaying human-friendly relative offsets alongside ISO 8601 UTC strings.
- DOM and theme initialization executes synchronously inside `<head>` to guarantee zero Flash of Unstyled Content (FOUC).
- Every runtime function maintains complete JSDoc documentation validated by `eslint-plugin-jsdoc` and `tsc --noEmit` (`checkJs: true`).

## Integration Contracts

- Reuses the central hub design system (`../index.css`) and shared theme switcher (`../index.js`).
- Exposed on the central portal (`dist/index.html`) as an active utility card searchable via `#search-input`.
- Test harness integration: Unit test coverage in `test/unit/jwt.test.ts` (Vitest with real Web Crypto HMAC vectors) and end-to-end integration in `test/e2e/jwt.spec.ts` (Playwright).

## Anti-Patterns

- Proxying JWT decoding or signing through a backend or Cloudflare Worker, which would compromise user secrets and invalidate the privacy guarantee.
- Importing external JWT runtime libraries (such as `jsonwebtoken` or `jose`), adding unnecessary JavaScript weight when browser Web Crypto provides native HMAC primitives.
- Bypassing input sanitization or failing to handle malformed base64/JSON tokens gracefully in the UI.
