# Platform Test Suite & CI Quality Gate

## Purpose and Design Decisions

`test/` houses the unified automated verification pipeline for `dev.gregorium.com`, combining static analysis (JSDoc validation on `.js` runtime files and ESLint on `.ts` test/config files), fast isolated unit tests in **Vitest** (`test/unit/*.test.ts`), and full browser end-to-end tests in **Playwright** (`test/e2e/*.spec.ts`). The E2E harness (`test/e2e/server.ts`) runs the real `dist/api/chatgpt.js` serverless handler on port `4173` and the real `worker/src/index.js` Cloudflare Worker on port `8787` with deterministic upstream fixtures so CI runs on every Pull Request without external network flakiness.

## Invariants

- All production JavaScript files (`dist/**/*.js`, `worker/src/**/*.js`) carry complete JSDoc annotations enforced by `eslint-plugin-jsdoc` and `tsc --noEmit` (`checkJs: true`) via `npm run lint:jsdoc`.
- All TypeScript test and configuration files (`test/**/*.ts`, `vitest.config.ts`, `playwright.config.ts`) pass strict `typescript-eslint` checks (`@typescript-eslint/no-explicit-any`, `consistent-type-imports`, `no-unused-vars`) via `npm run lint:ts`.
- Unit tests (`test/unit/*.test.ts`) execute in Vitest with `jsdom` (`npm run test:unit`) and cover every frontend module (`hub`, `indexnow`, `chatgpt-exporter`) and backend proxy (`chatgpt-api`, `worker-proxy`) without external network calls.
- Playwright E2E tests (`test/e2e/*.spec.ts`) run against `test/e2e/server.ts` (`npm run test:e2e`), which serves `dist/` and `/api/chatgpt` on `http://127.0.0.1:4173` and emulates the Cloudflare Worker on `http://127.0.0.1:8787`.
- GitHub Actions (`.github/workflows/ci.yml`) runs `.keystone/bin/keystone stone doctor --strict`, `npm run lint:jsdoc`, `npm run lint:ts`, `npm run test:unit`, and `npm run test:e2e` on every Pull Request and push to `main`.

## Integration Contracts

- `npm run lint`: runs `lint:jsdoc` and `lint:ts`.
- `npm run test:unit`: runs `vitest run` over `test/unit/**/*.test.ts`.
- `npm run test:e2e`: runs `playwright test` over `test/e2e/**/*.spec.ts`.
- `npm test`: executes `lint`, `test:unit`, and `test:e2e` sequentially.

## Anti-Patterns

- Relying on live third-party calls to `chatgpt.com` or `api.indexnow.org` during CI test runs, which introduces rate-limit and bot-protection failures on cloud runners.
- Adding functions to `dist/**/*.js` or `worker/src/**/*.js` without JSDoc `@param` and `@returns` annotations, or using `any` in `.ts` test files.
