# Cloudflare Worker Proxy

## Purpose and Design Decisions

`worker/src/index.js` (configured via `worker/wrangler.jsonc`) provides a stateless Cloudflare Worker proxy for operations blocked by browser CORS policies: verifying hosted IndexNow key files, downloading remote XML sitemaps, submitting URL batches to IndexNow search engines, and providing an edge fallback for ChatGPT share extraction. Hosting this proxy on Cloudflare Workers leverages the free tier's 100,000 daily requests and binds `DEV_INDEXNOW_KV` for per-IP abuse prevention without database infrastructure. See [`docs/index_now/API_LIMITS.md`](../../docs/index_now/API_LIMITS.md) for full rate-limit specifications.

## Invariants

- Rate-limited actions (`sitemap`, `submit`, `chatgpt_share`) enforce a maximum of **500 requests per IP per 24 hours (`86400s`)** and a **2-second cooldown (`2000ms`)** between consecutive requests from the same `CF-Connecting-IP` via `enforceRateLimit` in `DEV_INDEXNOW_KV`, returning HTTP `429` when exceeded.
- `enforceRateLimit` fails open (`{ limited: false, reason: null }`) if `DEV_INDEXNOW_KV` is unavailable or throws a read/write error, ensuring service continuity for legitimate users when KV limits or transient errors occur.
- Sitemap responses (`action=sitemap`) abort after 8 seconds and reject payloads larger than 2 MB (`2 * 1024 * 1024` bytes) with HTTP `400` to prevent memory exhaustion and DoS-by-proxy abuse.
- IndexNow submissions (`action=submit`) iterate sequentially through `api.indexnow.org`, `www.bing.com`, and `yandex.com`, returning immediately on the first `200` or `202` response with `engineVerified` set to the succeeding endpoint.

## Integration Contracts

- Base route: `/api/indexnow?action=<verify|sitemap|submit|chatgpt_share>` accepting `OPTIONS` (CORS preflight), `GET`, and `POST`.
- `action=verify`: accepts `{ key, keyLocation }`, fetches `keyLocation` (5s timeout), and returns HTTP `200` with `{ success: boolean, error?: string }`.
- `action=sitemap`: accepts `{ sitemapUrl }`, returns raw `text/xml` on `200` or JSON `{ error }` on `400`/`429`/`500`.
- `action=submit`: accepts `{ host, key, keyLocation?, urlList }`, forwards to IndexNow endpoints, and returns upstream status and JSON body plus `engineVerified`.

## Anti-Patterns

- Failing closed when Cloudflare KV is unreachable or unbound in local development, which would block all submissions during KV outages.
- Removing the 2 MB payload limit or timeouts on `action=sitemap`, which exposes the Worker to memory exhaustion from huge remote files.
